# ไทยช่วยไทย Plus

เว็บ React + Tailwind CSS สำหรับคำนวณรัฐช่วยจ่าย 60% สูงสุด 200 บาทต่อวัน เน้นใช้งานบนมือถือ

## การใช้งาน

1. กรอก **สิทธิ์รัฐที่เหลือวันนี้** ตั้งแต่ 0–200 บาท หากใช้สิทธิ์ไปแล้ว ให้ปรับยอดเอง
2. กรอก **ยอดซื้อครั้งนี้**
3. ดูกล่อง **คุณจ่ายทั้งหมด** สีน้ำเงิน, **รัฐช่วยจ่าย** สีเขียว และ **จ่ายเพิ่มเพราะสิทธิ์ไม่พอ** สีแดง
4. ดู **สิทธิ์นี้ซื้อของได้ถึง** เพื่อทราบยอดซื้อสูงสุดโดยไม่จ่ายส่วนเพิ่ม และกด **ใช้ยอดนี้** เพื่อคำนวณได้ทันที

ยอดจ่ายเพิ่มรวมอยู่ในยอดที่คุณจ่ายทั้งหมดแล้ว ทุกครั้งเป็นการจำลอง **ไม่หักสิทธิ์และไม่บันทึกธุรกรรมอัตโนมัติ**

รองรับตัวเลขไทย เครื่องหมายคั่นหลักพัน และทศนิยมไม่เกิน 2 ตำแหน่ง มีแถบสรุปติดด้านล่างบนมือถือ และแจ้งข้อมูลที่กรอกไม่ถูกต้องทันที

ช่องกรอกไม่รับตัวอักษร เครื่องหมายลบ หรือข้อความอย่าง `1e3` ทั้งตอนพิมพ์และวางข้อความ หากพบข้อความที่ไม่รองรับ จะเก็บยอดก่อนหน้าไว้และแจ้งเตือน ไม่ตัดตัวอักษรทิ้งจนยอดเงินเปลี่ยนความหมาย

## LocalStorage

- จำสิทธิ์ที่กรอกและยอดซื้อล่าสุดทันทีในเบราว์เซอร์นี้ ด้วยคีย์ `thai-plus:daily-draft:v1`
- เปิดใหม่ในวันเดียวกันแล้วคืนค่าล่าสุด
- เมื่อขึ้นวันใหม่ตามเขตเวลา `Asia/Bangkok` เริ่มสิทธิ์ 200 บาทและล้างยอดซื้อ พร้อมข้อความแจ้ง
- ตรวจวันใหม่เมื่อกลับมาเปิดแท็บและขณะเปิดค้างไว้
- ปิดการเข้าถึง LocalStorage ก็ยังคำนวณได้ แต่จะไม่จำข้อมูลหลังปิดหน้าเว็บ
- ล้างค่าที่จำไว้ได้ในหัวข้อ “จำข้อมูลไว้อย่างไร?”
- ไม่ส่งยอดเงินไปเซิร์ฟเวอร์ ไม่เชื่อมกับแอปรัฐหรืออุปกรณ์อื่น

React 19, TypeScript, Tailwind CSS 4, Vinext/Vite และ Lucide

## สูตรคำนวณ

คำนวณเป็นจำนวนเต็มหน่วยสตางค์:

1. เงินรัฐตามสัดส่วน = 60% ของยอดซื้อ ปัดเป็นสตางค์ใกล้ที่สุด
2. รัฐจ่ายจริง = ค่าที่น้อยที่สุดระหว่างเงินรัฐตามสัดส่วน, สิทธิ์ที่เหลือวันนี้ และ 200 บาท
3. ผู้ใช้จ่ายทั้งหมด = ยอดซื้อ − รัฐจ่ายจริง
4. จ่ายเพิ่มเพราะสิทธิ์ไม่พอ = เงินรัฐตามสัดส่วน − รัฐจ่ายจริง
5. สิทธิ์ที่จะเหลือหลังซื้อ = สิทธิ์วันนี้ − รัฐจ่ายจริง (เป็นยอดจำลอง)

ตัวอย่าง: ซื้อ 500 บาท มีสิทธิ์วันนี้ 200 บาท → รัฐจ่าย 200 บาท ผู้ใช้จ่าย 300 บาท ประกอบด้วยส่วนปกติ 200 บาทและจ่ายเพิ่ม 100 บาท

ยอดซื้อสูงสุดใช้การปัดเศษเดียวกัน: เมื่อสิทธิ์คงเหลือ A สตางค์ ยอดซื้อสูงสุดเท่ากับ `floor((5 × A + 2) / 3)` สตางค์ เช่น สิทธิ์ 200 บาท ซื้อได้ถึง 333.34 บาท รัฐจ่าย 200 บาท ผู้ใช้จ่าย 133.34 บาท หากเพิ่มเป็น 333.35 บาท จะมีส่วนเพิ่ม 0.01 บาท

อัตราและวิธีปัดเศษเป็นกติกาของเครื่องมือตามโจทย์ ไม่ได้เชื่อมต่อหรือรับรองเงื่อนไขโครงการทางการ
